An Arduino sketch that controls a DC motor's speed with a potentiometer and displays the current speed value on an LCD screen. Perfect for learning motor control, PWM, and real-time feedback!

What It Does

Reads a potentiometer and uses it to control motor speed, while showing the exact speed value (0-255) on an LCD display in real-time:

Turn dial left → Motor stops, LCD shows "0"
Turn dial middle → Motor at half speed, LCD shows "~512"
Turn dial right → Motor at full speed, LCD shows "1023"
