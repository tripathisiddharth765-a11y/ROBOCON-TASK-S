ASSINGMENT1-
An Arduino sketch that uses a potentiometer to control which LED is on and how bright it is. Great for creating mood lighting, traffic light simulators, or learning analog input with PWM output!

What It Does

Turns a potentiometer into a 3-zone brightness controller:

Green Zone (0-340) → Green LED with variable brightness
Yellow Zone (341-680) → Yellow LED with variable brightness
Red Zone (681-1023) → Red LED with variable brightness

ASSIGNMENT2 - 

An Arduino sketch that combines distance sensing with a customizable warning system. Think of it as a parking sensor or collision avoidance system for your robots!

What It Does

Uses an ultrasonic sensor to measure distance to an object and shows real-time alerts via LEDs:

Green — Safe distance (object far away)
Yellow — Warning zone (object getting closer)
Red  — Danger zone (object too close!)
ASSIGNEMNT - 

A simple Arduino sketch that lets you control LED brightness with a potentiometer. Perfect for learning analog input and PWM output!

What It Does

Reads a potentiometer (variable resistor) and uses its value to adjust LED brightness. Turn the dial left → dimmer. Turn right → brighter. That's it!

Super simple, but incredibly useful for understanding how embedded systems work.
