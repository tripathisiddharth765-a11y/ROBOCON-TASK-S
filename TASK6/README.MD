ASSIGNMENT - 
An Arduino sketch that uses an ultrasonic sensor to measure distance and automatically adjust LED brightness. The closer an object, the brighter the LED!

Perfect for learning sensor fusion and adaptive lighting systems.

What It Does

Measures distance to an object and maps it to LED brightness:

Far away (>200 cm) → LED off
Close (20-200 cm) → LED gets brighter as object approaches
Too close (<20 cm) → LED off (safety zone)

ASSIGNMENT - 
An Arduino sketch that creates a smooth crossfade between two LEDs using a single potentiometer. As you turn the dial, one LED fades out while the other fades in — perfect for visual effects or learning PWM control!

What It Does

Uses a potentiometer to control two LEDs with an automatic hand-off:

Left half of dial → LED2 brightens (LED1 off)
Right half of dial → LED1 brightens (LED2 off)
Middle position → Both LEDs at half brightness (smooth transition)
