An Arduino sketch that converts decimal numbers (0-15) into binary and displays them on 4 LEDs. A hands-on way to visualize how computers think!

What It Does

Takes a decimal number from your serial monitor and lights up LEDs to show its binary representation:

Decimal 5 → Binary 0101 → LEDs 2 and 4 light up
Decimal 15 → Binary 1111 → All LEDs light up
Decimal 0 → Binary 0000 → No LEDs light up
