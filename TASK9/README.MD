An Arduino sketch that controls a servo motor with a potentiometer and displays the current angle on an LCD screen. Perfect for learning servo control, I2C communication, and real-time feedback systems!

What It Does

Reads a potentiometer and uses it to control a servo, while showing the exact angle on an LCD display in real-time:

Turn dial left → Servo goes to 0°, LCD shows "0"
Turn dial middle → Servo goes to 90°, LCD shows "90"
Turn dial right → Servo goes to 180°, LCD shows "180"
