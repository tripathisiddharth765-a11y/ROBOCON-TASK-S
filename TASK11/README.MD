An Arduino sketch that controls a stepper motor and displays the current step count on an LCD screen. Perfect for learning stepper motor mechanics, step control, and real-time feedback systems!

What It Does

Controls a stepper motor to take exactly 200 steps in one direction while displaying the step count in real-time on an LCD:

Sends 200 step pulses to the stepper motor
Displays each step count (1-200) on LCD
Rotates motor one full revolution (200 steps = typical stepper motor revolution)
Repeats continuously
