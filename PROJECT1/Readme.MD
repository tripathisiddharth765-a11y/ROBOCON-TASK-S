An Arduino sketch that reads temperature from a sensor and automatically adjusts motor speed based on the reading. Perfect for learning sensor-based automation and creating temperature-responsive systems like cooling fans!

What It Does

Reads temperature from a thermal sensor and uses it to control motor speed automatically:

Cold (< 0°C) → Motor off or very slow
Room temp (20-25°C) → Motor at medium speed
Hot (80-125°C) → Motor at full speed
Displays temperature on LCD screen in real-time
